# 벤치마크 결과 (2026-10-26)

`maskara bench`로 낸 숫자다. 다시 내려면 `uv sync --all-extras --all-groups` 후 아래를 실행한다.

```
maskara bench --corpus <corpus> --system <system>
```

출력과 점수는 `runs/`에 남는다(git에는 올리지 않는다). 측정 정의는 `src/maskara/bench/score.py` 상단에 있다.

공개 수치는 외부 코퍼스 세 개를 기준으로 한다. 우리가 만든 linked는 따로 보고한다(설계 문서의 2026-10-26 결정).

## 직접식별자 누출 (낮을수록 좋다)

직접식별자 mention 중 모든 단어가 그대로 남은 비율이다.

| 시스템 | ABCD | Nemotron-PII | TAB | TAB + `legal-echr` 팩 |
|---|---:|---:|---:|---:|
| Presidio (기본값) | 17.9% | 21.9% | 37.6% | |
| GLiNER2-PII | 8.2% | 19.3% | 41.2% | |
| OpenAI Privacy Filter | 6.5% | 18.4% | 50.9% | |
| maskara, 규칙만 | 27.4% | 30.4% | 40.6% | |
| **maskara, 규칙 + GLiNER2 (기본값)** | **2.4%** | **4.9%** | 37.3% | **2.5%** |

- TAB의 직접식별자는 이름 228건과 사건번호(`no. 36110/97`) 134건이다. 범용 시스템은 모두 사건번호를 거의 다 놓친다. maskara 기본값도 100%를 놓친다. 반면 maskara 기본값의 이름 누출은 0.4%다.
- 사건번호 규칙은 코어에서 빼고 `legal-echr` 팩으로 옮겼다. 팩은 사용자가 `--pattern legal-echr`로 켠다. 팩을 켜도 ABCD와 Nemotron 결과는 한 자리도 바뀌지 않았다.

## 데이터가 뭉개졌는가 (높을수록 좋다)

- 구별성(distinctness): 서로 다른 사람이 서로 다른 값으로 남는가.
- 일관성(consistency): 같은 사람이 같은 값으로 남는가.

| 시스템 | 구별성 ABCD / Nemotron / TAB | 일관성 ABCD / Nemotron / TAB |
|---|---|---|
| 정답 span을 전부 `[CATEGORY]`로 가림 (완벽한 탐지 + 가림) | 71.2% / 65.6% / 20.4% | 100% / 100% / 99.6% |
| Presidio 가림 | 84.5% / 74.6% / 22.6% | 98.4% / 99.1% / 99.4% |
| Presidio + Faker (mention마다 새 값) | 99.8% / 92.5% / 99.6% | 69.0% / 78.8% / 88.5% |
| Presidio + Faker (문서 안에서 같은 값) | 99.8% / 92.5% / 99.6% | 97.1% / 95.6% / 98.8% |
| **maskara 기본값** | **96.9% / 92.7% / 99.8%** | **98.8% / 97.6% / 99.7%** |

- 탐지가 완벽해도 가림 처리는 사람을 뭉갠다. TAB에서 구별성이 20%다. 판결문에 나오는 여러 사람이 모두 `[PERSON]`이 된다.
- 문서 안에서 같은 값을 쓰는 Faker도 문서를 넘어가면 일관성이 깨진다. linked에서 일관성은 51.6%다.

## linked (따로 보고)

| 시스템 | 직접 누출 | 일관성 (문서 간) | 구별성 |
|---|---:|---:|---:|
| Presidio 가림 | 11.2% | 98.6% | 4.1% |
| OpenAI Privacy Filter | 12.8% | 99.6% | 1.7% |
| Presidio + Faker (문서 안에서 같은 값) | 11.5% | 51.6% | 99.0% |
| maskara, 텍스트만 | 35.8% | 98.7% | 96.2% |
| maskara, 표 + 텍스트 | 0.0% | 99.5% | 96.9% |

maskara의 0.0%는 표에서 아는 값을 텍스트에서 찾은 결과다. 같은 엔진에 텍스트만 넣으면 35.8%다. 텍스트만 받는 도구와 같은 조건의 비교가 아니다.

## 아직 남은 것

- **준식별자는 대부분 남긴다.** 기본 preset(balanced)이 그렇게 설계되어 있다. 준식별자 누출은 Nemotron 54.9%, TAB 35.0%다. 인구통계는 약 88%를 그대로 남긴다. 재식별 위험을 측정하지 않았으므로 이 정책이 맞는지 아직 모른다.
- **실제 유용성은 측정하지 않았다.** 구별성과 일관성은 대리 지표다. 마스킹한 데이터로 질의응답이나 분석을 해서 결과가 유지되는지는 linked에서만 측정했다.
- **Nemotron의 ID 누출이 12.9%다.** 남은 직접 누출 중 가장 크다.
- **채점 규칙.** 형식 단어(`https`, `com`, `Avenue`)와 mention 앞의 코드(`CUS-`, `1-`)는 남아도 누출로 세지 않는다. 테스트는 `tests/test_score.py`에 있다.

## 버전

- Presidio: spaCy `en_core_web_lg` 3.8.0, `preshed<3.0.14`
- GLiNER2: `fastino/gliner2-privacy-filter-PII-multi`, threshold 0.5
- OpenAI Privacy Filter: `opf` git f7f00ca
- 패키지 버전은 각 `runs/*.json`의 `versions`에 기록된다
